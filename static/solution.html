Solution

Solving the system of equations:

    a + b + c + d = 7.11
    a × b × c × d = 7.11

There is not one unique solution

The system has four unknowns but only two equations, so it has an infinite family of solutions. Pick any non-zero values for a and b, then solve for c and d using their required sum and product. 

    c + d = 7.11 − a − b
    c × d = 7.11 ÷ (a × b)

    c,d = ((7.11 − a − b) ± √((7.11 − a − b)² − 4 × 7.11 ÷ (a × b))) ÷ 2

Real-number choices for c and d exist when the discriminant is non-negative. If it is negative, the same formula gives a complex conjugate pair.
